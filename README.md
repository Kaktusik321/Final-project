# Vitamin D analysis

Postgraduate studies course project. The database contains synthetic patient data. 

## 1. Project Description
A web application developed in Python using the Streamlit library. It is used to analyze sample patient data, with a particular focus on vitamin D levels, the prevalence of asthma and allergies, and symptoms.
The application allows users to load data from a CSV file, filter records, analyze data, visualize results, and generate a report in PDF format.

## 2. Features

* Importing patient data from a CSV file.
* Filtering data by gender, asthma, and allergies.
* Vitamin D level analysis.
* Patient subgroup analysis.
* Data visualization using charts.
* Generating a PDF report based on the analyzed data.

## 3. Installation and running
1. Install Python.
2. Download the project repository from GitHub.
3. Open a terminal in the project folder.
4. Install the required libraries:
```bash
pip install -r requirements.txt
```
5. Run the application:
```bash
python -m streamlit run dashboard.py
```
The application will open in your web browser.

## 6. The use of AI tools

During the project, ChatGPT was used as a tool to support the process of programming and documenting the application.
It supported the development and debugging of the Streamlit application, including data analysis with pandas, data visualization with Matplotlib and Seaborn, and PDF report generation with ReportLab.
